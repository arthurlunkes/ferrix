# Code of Conduct

Ferrix is a friendly project and we want everyone to feel welcome, whatever their
experience level — first contributions are especially welcome.

## Our standards

- Be respectful and patient; assume good intent.
- Give constructive feedback about code, not people.
- No harassment, insults, discrimination or unwelcome attention of any kind.

## Enforcement

Report unacceptable behavior to the maintainer at **arthur.lunkes2017@gmail.com**.
Reports will be handled confidentially. Maintainers may remove comments, commits or
contributors that violate this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

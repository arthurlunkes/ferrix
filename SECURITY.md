# Security Policy

Ferrix is a network-facing server, so security reports are taken seriously.

## Reporting a vulnerability

**Please do not open a public issue for security problems.** Instead, use
[GitHub private vulnerability reporting](https://github.com/arthurlunkes/ferrix/security/advisories/new)
or email **arthur.lunkes2017@gmail.com**.

Include a description, steps to reproduce and the affected version. You should get a
reply within a few days; once fixed, you'll be credited in the release notes (unless you
prefer otherwise).

## Supported versions

Only the latest release receives security fixes while the project is pre-1.0.
